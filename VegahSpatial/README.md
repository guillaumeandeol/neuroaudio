# VegahSpatial

Version à part de Vegah : tâche de compréhension de la parole dans la parole (CRM français) spatialisée, un seul masqueur.

- `dev.html` : version développeur, fichier autonome (double-clic). Choix de l'angle de la cible et du masqueur à chaque essai (plan graphique, séparation symétrique par rapport au droit devant, distance à l'auditeur constante), spatialisation HRTF Web Audio, option d'enchaînement des essais sans réponse, journal et export CSV.
- Le corpus (`2-Validated-corpus`, fichiers `T5_F_Delta_Rouge_2.wav`) n'est pas dans le dépôt : on le charge depuis le disque avec « Choisir le dossier du corpus… ».
- Casque obligatoire ; HRTF générique du navigateur, niveau non calibré. Outil de recherche en développement.
